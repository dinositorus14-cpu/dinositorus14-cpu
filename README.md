# Commit Catcher

Game web sederhana: tangkap commit hijau yang jatuh dengan branch `main`, hindari bug merah. Commit yang terlewat atau bug yang tertangkap mengurangi nyawa.

## Kontrol
- Keyboard: `←` `→` (atau `A` `D`), `Enter`/`Spasi` untuk mulai
- Layar sentuh / mouse: geser di area game

## Deploy ke GitHub Pages
1. Buat repository baru di GitHub (misalnya `commit-catcher`).
2. Upload `index.html` dan `README.md` ke repository.
3. Buka **Settings → Pages**.
4. Pada **Build and deployment**, pilih **Deploy from a branch**, branch `main`, folder `/ (root)`, lalu **Save**.
5. Tunggu 1–2 menit. Game bisa dibuka di `https://USERNAME.github.io/commit-catcher/`.

## Lisensi
Bebas dipakai dan dimodifikasi.
